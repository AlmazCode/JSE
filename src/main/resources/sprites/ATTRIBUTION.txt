JSE original sprite artwork

The six Forest and Space PNG sprites are original artwork authored for this
repository. No third-party images, fonts or textures are included in them.

Editable source: tools/generate_sprites.py in the source repository.
Rebuild with: python3 tools/generate_sprites.py
The generator uses the Python standard library only; Python is not needed to
build or run the Java application. Each image is a transparent 32x32 RGBA PNG.

Integration paths (relative to the classpath):
  sprites/forest/player.png
  sprites/forest/enemy.png
  sprites/forest/pickup.png
  sprites/space/player.png
  sprites/space/enemy.png
  sprites/space/pickup.png

Forest: ranger, mushroom enemy, golden fruit.
Space: astronaut, robot enemy, energy crystal.
